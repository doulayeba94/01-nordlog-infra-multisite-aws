# Étape 0 — Cadrage de la mission

## Contexte
Cf. README principal. La direction NORDLOG commande une mission d'audit et de modernisation suite à une panne WMS de 8h ayant immobilisé l'entrepôt de Lyon.

## À produire
1. **Périmètre** : quels sites, quels systèmes (réseau, serveurs, WMS, ERP) sont couverts ? Qu'est-ce qui est explicitement hors périmètre ?
2. **Objectifs de la mission** (3 à 5 objectifs mesurables)
3. **Référentiel(s) mobilisé(s)** : à choisir et justifier (ex. bonnes pratiques ANSSI, ITIL pour la gestion d'incident, AWS Well-Architected Framework pour le volet cloud)
4. **Parties prenantes** : tableau rôle / implication (direction, IT interne, responsables d'entrepôt, auditeur)
5. **Contraintes** : reprendre et compléter celles données en contexte (budget, RTO/RPO, délai) — en identifier si besoin d'autres implicites (ex. continuité d'activité pendant la migration)

## Livrables
- [ ] Lettre de mission (périmètre, objectifs, référentiels, parties prenantes, contraintes)
